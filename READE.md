# FinPulse - Smart Financial Intelligence & Budgeting Platform

A client-side personal finance manager built with React, Vite, and Tailwind CSS. FinPulse helps users track income, control expenditure against monthly budgets, and analyze category distributions with zero server maintenance.

## Highlights
- **100% Serverless & Zero Setup**: No external database or API keys required; leverages HTML5 `localStorage`.
- **Instant CSV Export**: Export formatted accounting records to open directly in Microsoft Excel or Google Sheets.
- **Budget Health Tracking**: Visual real-time indicator alerting when expenditure exceeds predefined targets.
- **Micro-interactions**: Particle celebration effects on income booking and reactive state management.
